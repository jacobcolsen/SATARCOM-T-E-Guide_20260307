# Project instructions

- After completing a set of changes (a fix, feature, etc.), commit them and push to `origin main` on GitHub without asking for confirmation first. This is a standing authorization — no need to re-confirm each time.
  - Still use judgment: don't push obviously broken/untested changes, don't force-push, and don't push secrets. If a change is risky or the user seems mid-review, say so before pushing rather than silently skipping the rule.
